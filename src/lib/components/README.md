# `lib/components/`

Svelte components, organized by purpose.

## Folders

- `ui/` — **shadcn-svelte primitives** (Button, Dialog, Input, etc.). Generated by the shadcn CLI. **Do not edit by hand** — re-generate or override via wrapper components if needed.
- `dashboard/` — UI components specific to the dashboard/library view.

**Note**: Feature-specific components for the viewer, highlights, and summary live in `src/lib/features/` instead.

## Conventions

- Feature components import primitives from `ui/` rather than from `bits-ui` directly — keeps the shadcn override path consistent.
- One component per file. PascalCase filenames (e.g. `CitationPill.svelte`).
- Component-specific state lives in `.svelte.ts` siblings (Svelte 5 runes).
